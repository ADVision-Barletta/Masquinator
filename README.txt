Il Genio del Masque — Widget interattivo per raccomandazioni menu ristorante.

== Description ==

Masquinator è un widget flottante che guida i clienti attraverso 6 domande sulle loro preferenze per raccomandare la cena perfetta.

**Funzionalità:**

* Widget flottante con design teatrale "Theatre Noir"
* 6 domande interattive sulle preferenze alimentari
* Raccomandazioni basate su tag e algoritmo di matching
* Supporto Google Sheets CSV e Custom Post Type WordPress
* Gutenberg block e shortcode `[masquinator]`
* Admin settings page per configurazione
* Totalmente personalizzabile (colori, font, testi)
* Responsive e accessibile

== Installation ==

1. Carica la cartella `masquinator` nella directory `/wp-content/plugins/`
2. Attiva il plugin dalla pagina "Plugin" di WordPress
3. Vai su Impostazioni > Masquinator per configurare il plugin
4. Inserisci `[masquinator]` in una pagina oppure usa il blocco "Masque Matchmaker"

== Shortcode ==

`[masquinator]`
